# Facade Pattern - 73464

A C# console-based user management system demonstrating the Facade Design Pattern.

## Features

- Add, display, update and delete users.
- Email validation and duplicate email prevention.
- User repository, authentication and notification services.
- Exception handling and input validation.
- Unified interface through the UserFacade class.

## Technologies

- C#
- .NET 10.0
- Facade Design Pattern
- SOLID principles

## Design Pattern

The UserFacade class simplifies user management by coordinating internal services and hiding implementation complexity from the client.

## How to Run

```bash
dotnet build
dotnet run
```
